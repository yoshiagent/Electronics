手柄的使用、連接配對說明(不同副廠產品會略有不同)

    PS2手柄由手柄和接收器兩個部分組成，手柄需要兩節AAA 1.5V供電，接收器的電源範圍為3~5V,不能接反，不能超電壓，過壓和反接，都會使接收器燒壞。

    手柄上有個電源開關，ON開/OFF關，將手柄開關打到ON上，在未搜索到接收器的狀況下，手柄上的燈會不停的閃，在一定時間內，還未搜索到接收器，手柄將進入待機模式，手柄上的燈將滅掉，這時，按下“MODE”鍵，喚醒手柄。

    接收器供電，在未配對的狀況在，綠燈閃。

    手柄打開，接收器供電，手柄和接收器會自動配對，這時接收器燈常亮，手柄配對成功。
按鍵“MODE”(手柄批次不同，上面的標識有可能是"ANALOG"，但不會影響使用)，可以選擇“紅燈模式”、“綠燈模式”。

若手柄和接收器不能正常配對！
多數問題是，接收器的接線不正確，或程式有問題。

解決方法：接收器只接電源（電源線一定要連接正確），不接任何資料線和時鐘線，一般情況下手柄是能夠配對成功。配對成功後燈常亮，說明手柄是好的。這時再檢查接線是否正確，程式移植是否有問題。

Sony game consoles called PlayStation, and you have probably held it at least once.
Sony game controllers have 12 analog keys sensitive to pressure, (4 keys for direction, 4 operation keys, Cross, Triangle, Circle, and Square, L1, L2, R1, and R2)
and 5 digital keys (MODE, START, SELECT, R3, L3)
and 2 analog joysticks.

There are 2 motors inside controllers that can make vibration because of their imbalance.

The wireless controller works with 2.4GHz frequency and it has a range of 10 meters.



The buttons with the coloured shapes can also be referred to by the names
PSB_TRIANGLE,
PSB_CIRCLE,
PSB_CROSS,
and PSB_SQUARE.

The buttons can be pressed,ButtonReleased, pressed and held,
or pressed with a varying pressure,
so there are a number of methods that can be applied to the buttons
and joystick.
The methods are;
ButtonPressed, ButtonReleased,Button, NewButtonState,and Analog.
Here are some examples of how these are used.

ps2x.ButtonPressed(PSB_RED) is for a simple press of the red circle button.

ps2x.ButtonReleased(PSB_CIRCLE)

ps2x.Button(PSB_PAD_DOWN) is for the down button on the pad being pressed and held.

ps2x.NewButtonState(PSB_CIRCLE)

ps2x.Analog(PSAB_CROSS) is the command for measuring the pressure applied to the “X” button, if pressure sensitivity has been enabled. As you can see the “PSAB” form of the name has been used for the button.

ps2x.Analog(PSS_RY) is the command to obtaining readings off the right joystick  in the vertical direction.

int valR;
uint8_t dL;
uint8_t dR;
byte vibrate = 0;
PS2X  ps2x;

int error = 1;


void setup() {
 
  pinMode( DirL , OUTPUT);
  pinMode( DirR , OUTPUT);
  while(error==1){
   error = ps2x.config_gamepad(PS2_CLK, PS2_CMD, PS2_SEL, PS2_DAT, pressures, rumble);
      delay(500);
  }
}

void loop() {
  if(error == 1) //skip loop if no controller found
   return;
  ps2x.read_gamepad(false, vibrate);
       valL=ps2x.Analog(PSS_LY);
       valR=ps2x.Analog(PSS_RY);
       valL=map(valL,0,255,255,-255);
       valR=map(valR,0,255,255,-255);
       Serial.println(valL);
       Serial.println(valR);
       dL=1;
       if(valL<5 && valL>-5)
         valL=0;
       if (valL<0)
         {valL=-valL;
          dL=0;  
         }
     
       dR=1;
       if(valR<5 && valR>-5)
         valR=0;
       if (valR<0)
         {valR=-valR;
          dR=0;  
         }
     digitalWrite(DirL,dL);
     digitalWrite(DirR,dR);
     analogWrite(PwmL,valL);
     analogWrite(PwmR,valR);

}
