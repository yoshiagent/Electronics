}

void loop()
{
  if(Serial.available())
  {
    s = Serial.readString();

      digitalWrite(LED1,LOW);

readString() 方法的行為是不論有無資料可讀取、也不論資料長度，都會等到 serial.setTimeout() 指定的工作時間(ms)截止後才返回。(若傳送字串長 timeout 時間需增加)
這段期間內讀取的資料全部放入字串 (String) 回傳。
String s=Serial.readString();
如果沒有資料，則字串長度為 0
s.length 為 0
