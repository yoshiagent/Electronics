# 應用電子學 / IoT Robot 教材網站

課程教材的獨立靜態網站,由 `myCourse/iotRobot` 整理而來:自 `index.html` 遞迴追蹤所有
站內連結,只收錄實際被連到的檔案。

## 內容

- 119 個教學網頁
- 圖片 / SVG / PDF / Arduino 函式庫與範例程式

## 線上版與本機版的差異

為配合 GitHub 限制,線上版**不含教學影片**(14 個 mp4,共 947 MB):

- GitHub 單檔上限 100 MB,其中 2 個影片為 488 MB / 142 MB
- GitHub Pages 站台上限 1 GB,含影片為 1206 MB

本機完整版(含影片)保留於 `C:\CludeHome\Electronics`。
