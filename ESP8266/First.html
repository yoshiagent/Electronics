Introduction

Access Point (AP): 允許其他無線設備聯入，提供無線連接無線網路的服務，無 線分享器就是結合Wi-Fi和路由功能的AP

Station (Sta) :連接到AP的裝置，一般可無線上網的3C產品(PC, 手機,平板...)通常都處於STA模式，STA模式不允許其他聯網裝置聯入

AP 會每隔100ms廣播它的識別名稱(Service Set IDentifier, SSID)，讓處於通訊範圍內的裝置辨識並加入網路。
多數的AP會設定密碼，Wi-Fi提供WEP, WPA或WPA2加密機制，彼此連線的裝置必須具備相同的加密功能，才能相連。
